## Setup

1. Put all files in your GitHub Pages repository.
2. Add your real images to the `images` folder.
3. Replace the placeholder LinkedIn URL in `index.html`.
4. Update the email address if required.
5. Commit and push to GitHub.
6. Open your GitHub Pages URL.

## Notes

- The site works without the optional images; emoji placeholders appear when an image is missing.
- The contact form opens the visitor's default email application.
- Project filters and case-study modals are handled by `script.js`.
- Replace the sample project descriptions with approved client-facing case studies.
